## Upload to GitHub
1. Unzip the download.
2. Open the Avish_Resume_Website folder. Upload its CONTENTS, including index.html, css, js, img, and vendor. Do not upload only the ZIP or nest the entire folder beneath your repository root.
3. Name your public repository YOUR-GITHUB-USERNAME.github.io, using your actual username.
4. Use the repository upload-files option, drag in the contents, and commit.
5. Enable GitHub Pages from the branch containing index.html at the root if it is not already enabled.

No package installation or build is needed.
